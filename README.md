# Markov Chains and Relaxation Time

This repository contains the report for a group project exploring Markov chains, stationary distributions, relaxation time, and their applications.

## Context

Markov chains are stochastic models in which the future state depends only on the current state. The project studies the conditions under which a Markov chain approaches a stationary distribution and examines how relaxation time describes the rate at which a system returns toward equilibrium.

## Project Overview

The project covers:

- Markov chains and transition matrices
- Irreducibility and aperiodicity
- Stationary distributions
- Continuous-time Markov chains
- Relaxation time and mixing time
- Applications in areas such as PageRank, epidemiology, spin systems, and population growth
